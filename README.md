# Sudoku Solver Web Application

### Description

A complete web app to input any Sudoku puzzle, check conflicts, solve it using a smart backtracking algorithm with multiple-solution detection, and interact via keyboard or on-screen number pad.

---

### Features

- Empty 9×9 grid on load.
- Manual entry of clues via keyboard or on-screen pad.
- Highlight selected cell, related row, column, and box.
- Distinguish user clues and solver answers by color.
- Validate entries and show conflicts.
- Solve puzzles, detect no solution or multiple solutions.
- Controls: Solve, Check Entries, Reset Solution, Clear All, Erase Cell, Undo.
- Responsive, accessible, modern UI with instructions.

---

### Requirements

- Node.js and npm installed.
